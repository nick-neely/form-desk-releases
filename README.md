# Form Desk

Form Desk is a Windows app for keeping, filling in, editing and printing documents
made in Microsoft Publisher, without needing Publisher.

## Install

1. Open the [latest release](https://github.com/nick-neely/form-desk-releases/releases/latest).
2. Under **Assets**, download **Form-Desk-Setup-_version_.exe**.
3. Open the downloaded file. The installer is not code-signed, so Windows may show
   "Windows protected your PC". Choose **More info**, then **Run anyway**.
4. Form Desk installs for your Windows account and opens. It runs on 64-bit Windows.

Form Desk checks this page itself and offers each new version, with notes on what
changed. You do not need to come back here to update.

## What is here

This repository holds only Form Desk releases: the installer, the update files the
app downloads (`RELEASES` and the `.nupkg` package) and `form-desk-release.json`, which
carries each release's notes and file checksums.

The source code is private. To report a problem, use **Help** in Form Desk. This
repository does not accept issues or pull requests.
